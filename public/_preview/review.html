Shipments — Wave 1 & 2 (new)

Control tower, paperwork, freight money — without a single external service

  • Card surfaces: every shipment card now uses the theme’s own surface — solid white in the light theme, the deep panel colour in dark — with the colour kept for chips, icon badges and status pills (.master-card--flat is reusable by any module)
  • Control tower: ETA + delay reason on every shipment, “due in X days / X days overdue” chips, needs-attention counts (overdue, arriving ≤ 7 days, hold, docs pending, e-way expiring) and one-click saved views
  • Document vault: real document types (BL/AWB, invoice, packing list, shipping bill, BOE, COO, insurance, e-way) with a per-shipment ✓/✗ checklist per shipment type — a delivered shipment with missing paper raises a warning
  • Paperwork you can hand over: packing list, delivery challan and shipment summary print from the real item lines (browser print → Save as PDF)
  • Stickers with a scannable QR: hand-rolled local QR encoder — the code on the mark opens the public tracking page; print one shipment’s stickers or the whole open board
  • Money: freight cost breakdown (freight, insurance, duty, CHA, last-mile, demurrage, other) with INR conversion, paid heads mirrored into the cashflow ledger, invoice link with landed-cost margin and cost per kg
  • Clients: notify-on-status-change tick-box, six-step tracking stepper on the portal and a public page with day-by-day updates and WhatsApp share

Testing guide

How to review

1 · Breakpoints
Resize: ≥1200 desktop · 768–1199 tablet (toolbar wraps, tables scroll) · 481–767 mobile (kanban snap, 44px controls, safe-area) · ≤480 (full-bleed modal sheets).
2 · Themes
The Dark button (top bar, top-right) or a ?theme=dark link sets both themes and persists across pages via localStorage.
3 · Caveats
Static deck: sample data only, forms submit to # (nothing persists, no backend). Selects use the real Select2 init where the production page does.
